# REconddendity

Wrapper to the Fortran subroutine computing the conditional density of
the random effects

## Usage

``` r
REconddensity(
  ui0,
  Y0,
  X0,
  Tentr0,
  Tevt0,
  Devt0,
  ind_survint0,
  idea0,
  idg0,
  idcor0,
  idcontr0,
  idsurv0,
  idtdv0,
  typrisq0,
  nz0,
  zi0,
  nbevt0,
  idtrunc0,
  logspecif0,
  ny0,
  nv0,
  nobs0,
  nmes0,
  idiag0,
  ncor0,
  nalea0,
  npm0,
  b0,
  epsY0,
  idlink0,
  nbzitr0,
  zitr0,
  uniqueY0,
  indiceY0,
  nvalSPLORD0,
  idst0,
  nXcl0,
  Xcl_Ti0,
  Xcl_GK0,
  Xcs_Ti0,
  Xcs_GK0,
  nonlin0,
  centerpoly0
)
```
