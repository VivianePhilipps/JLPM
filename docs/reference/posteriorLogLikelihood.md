# Posterior density of the random effects for 1 subject

Posterior density of the random effects for 1 subject

## Usage

``` r
posteriorLogLikelihood(value, x, data)
```

## Arguments

- value:

  numeric vector containing the value at which the log-likelihood will
  be computed

- x:

  a `jointLPM` object

- data:

  a data.frame object containing the observations of a single subject

## Value

the conditional log-likelihood of the random effects given the observed
data
